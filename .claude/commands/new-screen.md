description: 신규 대시보드 화면을 표준 절차로 추가한다
argument-hint: <화면명>
---

새 화면 "$ARGUMENTS"을(를) 추가한다. 아래 순서를 반드시 지킨다 (CLAUDE.md §1-6 불변식).

1. **화면 정의 먼저**: `docs/screens.md` 표에 번호/화면구분/화면명/목적/데이터소스/상태(미착수)를 추가한다.
2. **데이터 소스 확인**: 이 화면이 사용할 지표가 `docs/data-sources.md`에 이미 정의되어 있는지 확인한다.
   없는 지표라면 먼저 그 문서에 출처를 추가한다 (불변식 §1-2).
3. **스코어링 의존 여부 확인**: 매수신호지수를 표시한다면 `docs/scoring-model.md`의 계산 모듈을 그대로 호출한다.
   절대 화면 컴포넌트 안에 계산 로직을 새로 구현하지 않는다 (불변식 §1-3).
4. **컴포넌트 스캐폴딩**: `web/app/` 하위에 라우트를, `web/components/`에 재사용 컴포넌트를 생성한다.
5. **반응형 및 빈 상태 처리**: 데이터 미수집 시(빈 배열) 화면이 깨지지 않는지 확인한다.
6. **`docs/screens.md` 상태를 "완료"로 갱신**한다.
7. 로컬에서 실제로 렌더링해 확인한다 (가능하면 브라우저로 직접 확인).
