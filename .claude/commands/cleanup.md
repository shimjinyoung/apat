---
description: 미사용 코드/의존성/브랜치를 정리한다
---

다음을 순서대로 점검하고, 삭제 전에는 반드시 무엇을 왜 지우는지 먼저 보고한다.

1. **미사용 의존성**: `package.json`/`requirements.txt`에 있으나 코드에서 import되지 않는 패키지 탐색
2. **미사용 코드**: 어디서도 참조되지 않는 컴포넌트/함수/파일 (Grep으로 참조 카운트 확인 후 판단)
3. **오래된 브랜치**: `git branch --merged`로 이미 머지된 로컬 브랜치 확인 (원격/미머지 브랜치는 삭제하지 않음)
4. **훅 로그/임시 산출물**: `.claude/hooks` 실행 중 생성된 임시 파일, `data-pipeline/output/` 등 정리 대상 확인
5. **docs 정합성**: `docs/screens.md`, `docs/data-sources.md`에 이미 삭제된 화면/지표가 남아있지 않은지 확인

삭제는 되돌리기 쉬운 것(미사용 파일)부터 진행하고, 브랜치 삭제처럼 되돌리기 어려운 작업은
사용자 승인 후에만 실행한다(`git branch -D` 금지, `-d`만 사용).
