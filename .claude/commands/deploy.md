---

배포는 되돌리기 어려운 작업이므로, 아래 체크리스트를 모두 확인한 뒤 **사용자에게 명시적으로 승인받고** 진행한다.

## 배포 전 체크리스트
1. `docs/decisions/`에 배포 대상(Vercel 등)이 확정되어 있는가? 없다면 먼저 ADR을 작성하거나 사용자에게 확인한다.
2. 빌드가 로컬에서 성공하는가? (`pnpm build` 등 — 프로젝트 상태에 맞게 실행)
3. `.env`/시크릿이 배포 산출물에 포함되지 않는가? (`.gitignore` 및 배포 플랫폼의 환경변수 설정 확인)
4. `docs/scoring-model.md`와 실제 배포되는 코드의 스코어링 로직이 일치하는가?
5. 데이터 수집 배치(있다면)가 배포 환경에서도 정상 스케줄링되는가?

## 절차
1. 위 체크리스트 결과를 표로 사용자에게 보고한다.
2. "배포를 진행할까요?"라고 명시적으로 확인받는다.
3. 승인 후에만 배포 명령을 실행한다.
4. 배포 후 실제 URL에서 대시보드가 정상 로드되는지 확인한다.
