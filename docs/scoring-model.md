## 2. 채점 기준 (-1 / 0 / +1)
각 지표는 최신 추세를 기준으로 3단계로 채점한다. **실제 구현(`web/lib/classify.ts`)은 최근 두 시점의
전기 대비 변화율(%)이 임계치 미만이면 0, 이상이면 방향에 따라 ±1**이다(주간=전주, 월간=전월 비교).
전세수급지수만 100 기준선 절대수준(105 이상 +1, 95 이하 -1). 임계치: 매매가격지수·전세가격지수 ±0.05%,
매매거래량 ±15%, 낙찰률·낙찰가율 ±3%, 경매 진행건수 ±15%, 미분양 ±4%, 입주가구수 ±10%, 연체율 ±10%, **주담대 금리는 3개월 전 대비 ±0.25%p**
(§6 참고, 거래량·미분양만 백테스트, 나머지 잠정). 아래 표는 각 지표의 방향성 해석이며, "해석 방식 안내"
화면 §2는 classify.ts의 설정값을 그대로 읽어 표시한다.
⚠️ 매매거래량은 아래 표에 "전년 동월 대비"로 적혀 있으나 코드는 **직전 월 대비**로 비교한다(불일치, 확인 필요).

| 지표 | -1 | 0 | +1 |
|---|---|---|---|
| 낙찰률 | 하락 추세 지속 | 보합 | 저점 대비 반등 전환 |
| 낙찰가율 | 70~80%대에서 추가 하락 | 보합 | 80%대 초반~90% 근접 상승 전환 |
| 서울 아파트 경매 진행건수 | 건수 계속 증가(부실 확산) | 보합 | 정점 후 감소 전환(부실 정리) |
| 매매가격지수 | 하락폭 확대 | 하락폭 보합 | 낙폭 축소 또는 반등 전환 |
| 매매거래량 | 전년 동월 대비 감소 지속 | 보합 | 전년 동월 대비 뚜렷한 증가 |
| 전세가격지수(주간) | 하락·정체 지속 | 보합 | 상승 전환(갭투자 여력 확대 신호) |
| 전세수급지수 | 100 하회 지속·하락 | 보합 | 100 근접 또는 상회 전환 |
| 서울 미분양(월간) | 증가 추세 지속 | 보합 | 정점 통과 후 감소 전환 |
| 서울 아파트 월간 입주가구수 | 전월 대비 증가 추세 | 보합 | 전월 대비 감소 추세(공급절벽 국면) |
| 서울 주택담보대출 연체율 | 상승 추세 지속(부실 확산) | 보합 | 하락 전환(연체 정리 국면) |
| 주택담보대출 금리(신규취급액) | 3개월 전 대비 +0.25%p 이상 상승(매수 여력↓) | 변화폭 0.25%p 미만 | 3개월 전 대비 -0.25%p 이상 하락 |

## 3. 계산식
```
가중점수 = Σ(지표별 점수 × 가중치)              # 범위: -W ~ +W (W = 가중치 합계, 현재 12.0)
매수신호지수(0~100) = (가중점수 + W) / (2W) × 100     # 코드는 WEIGHT_SUM을 동적으로 사용
```

## 4. 해석 밴드

| 지수 | 해석 | 액션 가이드 |
|---|---|---|
| 0~30 | 비우호 국면 | 추가 하락 여지, 관망 |
| 30~50 | 하방 둔화, 관찰 필요 | 선행지표 전환 여부 매주 체크 |
| 50~70 | 전환 신호 누적 중 | 선행지표 2개 이상 우호 전환 시 매수 검토 시작 |
| 70~85 | 매수 우호 국면 | 다수 지표 동반 우호, 실행 검토 |
| 85~100 | 과열 진입 가능성 | 이미 가격 반영 다수 → 주의 |

## 5. 오버라이드 규칙
- 선행지표 4종(거래량·전세가격지수·전세수급지수·주담대 금리) 중 **2개 이상이 동시에 -1**이면, 가중합이 높아도 지수 상한을 **60점으로 캡**한다.
- 거시 변수 급변(기준금리 급등락, LTV·DSR 규제 발표) 발생 시 자동 산출을 **일시 정지**하고 수동 검토 플래그를 표시한다.

  기준으로 사용. **"수도권"(서울+인천+경기) 통합 수치는 확인해보니 공식 통계로 존재하지 않음** —
  서울·인천·경기가 시·도별로 각각 따로 제공될 뿐, 셋을 합치려면 대출잔액 가중평균이 필요한데
  그 가중치 데이터가 이 표에 없어 직접 계산이 불가능하다. 다른 9개 지표가 전부 "서울 단독" 기준인
  것과 일관성을 맞춰 **서울 단독**으로 확정(docs/data-sources.md 참고). 가중치 1.0, 성격은
  경매 진행건수와 유사한 "동행~후행"(연체는 이미 벌어진 부실을 반영하는 지표라 선행성은 약함).
  건수 상승=부실 확산(비우호), 하락 전환=연체 정리(우호)로 auction_case_count와 동일한 해석
  방향. 임계치는 실데이터 없어 잠정(§6 참고). 같은 날 ECOS Open API 키 발급 완료 →
  `ecos_delinquency.py`로 자동 수집기 구현 완료(STAT_CODE=141Y005, 계정항목=R5AB0C,
  지역코드=A00). 통계코드는 ECOS 메타데이터 API(StatisticTableList/StatisticItemList)로
  실제 조회해 확정 — KOSIS 때와 동일하게 추측하지 않는 원칙 적용. 월 데이터지만 확정 반영에
